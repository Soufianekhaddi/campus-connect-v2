# 📚 Campus Connect - Documentation

Welcome to Campus Connect! This documentation will help you understand how each page works in our React Native app.

## 📱 App Overview

Campus Connect is a mobile application that helps students discover campus events and internship opportunities. The app has 4 main pages:

- 🏠 **Home** - Dashboard with overview of opportunities
- 📅 **Events** - List of all campus events
- 💼 **Internships** - List of available internships
- 👤 **Profile** - User profile and settings

## 🔧 Technologies Used

- **React Native** - Mobile app framework
- **React Context** - State management for user authentication
- **JavaScript** - Programming language
- **Flexbox** - Layout system
- **StyleSheet** - Styling components
